# Ciancheiltis — Agent Routing

Pure Irish-language datasets (Gaois · Téarma · Logainm · Ainm · Canúint · Dúchas · UD) +
non-educational Celtic-language pipelines (Welsh · Scottish Gaelic · Breton · Manx · Cornish).

Pipeline: DLT sources → BAML extraction → CocoIndex v1 (bge-m3 1024-d) → DuckLake + LanceDB.

See `openspec/changes/2026-09-25-ciancheiltis-init-v1/proposal.md` for the carve-out plan.
